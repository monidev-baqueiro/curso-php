# Curso Intensivo de PHP

Repositório dedicado ao curso intensivo de PHP. Aqui vou concentrar todos os
exercícios, exemplos e projetos desenvolvidos ao longo das aulas.

O objetivo é estudar PHP de forma intensiva, praticando todos os dias e
documentando a evolução aula a aula.

## Estrutura

Cada pasta corresponde a um projeto do curso:

- `projeto1-UNES/` — site institucional fictício da universidade UNES
  (páginas: home, sobre e contato)
- `projeto2-discordpage/` — landing page inspirada no site do Discord
- `projeto3-detalhesdeproduto/` — página de detalhes de produto estilo
  e-commerce (iPhone 17 Pro Max), com layout inspirado no Mercado Livre e
  identidade visual da Americanas. Inclui galeria de fotos, seletor de
  memória que recalcula preço e parcelas, e caixa de compra.

## Como executar

Com o PHP instalado, rode um servidor local na raiz do projeto desejado:

```bash
cd projeto3-detalhesdeproduto
php -S localhost:8000
```

Depois acesse `http://localhost:8000/` no navegador.
