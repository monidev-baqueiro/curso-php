# Curso Intensivo de PHP

Repositório dedicado ao curso intensivo de PHP. Aqui vou concentrar todos os
exercícios, exemplos e projetos desenvolvidos ao longo das aulas.

O objetivo é estudar PHP de forma intensiva, praticando todos os dias e
documentando a evolução aula a aula.

## Estrutura

Cada pasta corresponde a uma aula ou módulo do curso:

- `aula-01/` — primeiros passos com PHP (exemplo curto de código)

## Como executar

Com o PHP instalado, rode um servidor local na raiz do projeto:

```bash
php -S localhost:8000
```

Depois acesse `http://localhost:8000/aula-01/` no navegador.
